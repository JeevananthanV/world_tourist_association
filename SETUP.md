# World Tourist Association (WTA) — Setup Guide

Welcome to the **World Tourist Association (WTA) Global Portal** setup guide. Built with React 18 and Vite.

- **GitHub Repository**: [https://github.com/JeevananthanV/world_tourist_association](https://github.com/JeevananthanV/world_tourist_association)
- **Author**: Jeevananthan V

---

## 📋 System Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/JeevananthanV/world_tourist_association.git
cd world_tourist_association
```

---

## 📦 2. Install Dependencies & Run Locally

```bash
cd "World Tourist Association/wta-site"
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🏗️ 3. Production Build

```bash
cd "World Tourist Association/wta-site"
npm run build
npm run preview
```
Output files will be generated in `World Tourist Association/wta-site/dist/`.
