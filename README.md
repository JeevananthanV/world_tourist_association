## 🌍 Modules & Pages

- **Home**: Hero showcases, international chapter locator, and trending travel itineraries.
- **About**: Global WTA vision, leadership council, and international advisory board.
- **Chapters**: Worldwide regional hubs and local tourism partnerships.
- **Membership**: Tiered benefits for travelers, certified guides, agencies, and operators.
- **Events**: Global summits, cultural exchanges, webinars, and eco-tourism workshops.
- **Sustainability**: Carbon-neutral initiatives, heritage conservation, and ethical travel guidelines.
- **Research & Publications**: Tourism trend reports and economic impact surveys.
- **Human Capital Development (HCD)**: Training certifications for hospitality professionals.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/JeevananthanV/world_tourist_association.git
cd world_tourist_association
```

### Installation & Run

```bash
cd "World Tourist Association/wta-site"
npm install
npm run dev
```

Open `http://localhost:5173` to explore the platform.
